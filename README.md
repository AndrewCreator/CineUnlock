# CineUnlock

Experimental firmware utility for the **Sony a7S III (ILCE-7SM3) on firmware 5.01**. The current preview is packaged for **macOS 15 or later on Apple Silicon**.

[Download CineUnlock for Sony a7S III](https://github.com/AndrewCreator/CineUnlock/releases/tag/v0.4.0-preview.2-glass-falsecolor.1)

The release contains the full desktop application, classic and minimal S-Log3 False Color LUTs, and third-party notices. Sony’s built-in Display LUT can use the `.cube` files independently.

**Hardware testing covered one Sony a7S III only, the maintainer’s own camera. A second body has not been tested.** An earlier modified 5.01 build installed from SD, and the camera returned to shooting. Shutter Angle and Variable Shutter worked. Separate tests on the same body verified that BIG6 survived a power cycle and that temporary De-Squeeze worked on the LCD.

This exact build passed offline checks with simulated hardware. Its camera installation, recovery and False Color display remain unverified. The macOS app uses an ad hoc signature.
